# Module 1 – Network Topology Portfolio

## 🧠 Objective
Design a basic network topology demonstrating understanding of the **Core, Distribution, and Access layers** using Cisco Packet Tracer.

## 📄 Files Included
- `M1_Topology_Labeled_Portfolio.pkt` – Packet Tracer file of the complete topology  
- `M1_portfolio_description.md` – Detailed description of devices, IP scheme, and configuration steps  
- `screenshots/` – Images showing topology, device labels, and command outputs  

## ⚙️ Tools Used
- Cisco Packet Tracer v8.x  
- Markdown (.md) for documentation  

## 🔍 Summary
This topology demonstrates how to:
- Categorize devices into Core, Distribution, and Access layers  
- Assign IP addresses to each network segment  
- Verify connectivity using the Command Prompt in Packet Tracer
