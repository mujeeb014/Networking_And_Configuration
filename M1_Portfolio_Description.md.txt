## 📘 Overview
This project demonstrates a **three-tier hierarchical network topology** consisting of Core, Distribution, and Access layers.

The design follows Cisco’s recommended model for scalable and manageable enterprise networks.

---

## 🧩 Network Layers

### 🔴 Core Layer
- **Device:** R1_Core  
- **Function:** Routes and manages traffic between networks.

### 🟡 Distribution Layer
- **Devices:** S1_Dist, S2_Dist  
- **Function:** Aggregates Access Layer and enforces network policies.

### 🟢 Access Layer
- **Devices:** PCs, Laptops, Wireless Access Points  
- **Function:** Provides network access to end users.
