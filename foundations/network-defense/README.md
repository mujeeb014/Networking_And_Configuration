# Network Defense Coursework

Notes and labs from Cisco NetAcad's Network Defense course, currently in progress.

I'm documenting this with one extra question in mind for every topic: **"If I were attacking this instead of defending it, what would I look for?"** That framing is what turns standard coursework into pentesting-relevant material.

## Notes format

For each topic, I'm aiming to capture:
1. **The defensive concept** — what it does, how it's configured
2. **The attacker's view** — how this control is commonly bypassed or misconfigured in the real world
3. **The tell** — what evidence/logs would show if this control failed or was bypassed
