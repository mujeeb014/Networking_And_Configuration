# Foundations

This folder holds my Cisco Networking Academy (NetAcad) coursework. While these courses are defense/networking-focused rather than offensive security, they're the foundation everything else depends on — you can't exploit a network you don't understand.

As I go through each module, I try to note not just *what* I configured, but *what an attacker could do with this*, and *what a defender should watch for*. That dual perspective is the through-line connecting this folder to the rest of the portfolio.
