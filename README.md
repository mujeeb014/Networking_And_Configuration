---

## Why this repo is structured this way

Most beginner security portfolios are just a pile of CTF flags. This one is organized around the **penetration testing methodology** — recon, enumeration, exploitation, privilege escalation, reporting — because that process, not any single tool or flag, is what I'm actually being evaluated on by anyone hiring for a pentesting role.

Even my current networking/defense coursework lives here, framed through that lens: understanding how defenders configure and monitor a network directly informs how I'd attack — and later evade — one.
